# CardioKB: Cardiovascular Disease Knowledge Base

## Overview
CardioKB is a comprehensive knowledge base integrating biomedical data from multiple sources to support cardiovascular disease research, feature selection, and precision medicine applications.

## Project Structure
```
Cardio-KB/
├── data/           # Raw and processed data files
├── docs/           # Documentation and planning
├── models/         # (Future) ML models
├── ontology/       # Ontology design files
├── scripts/        # Data processing scripts
├── tests/          # Test files
├── web/            # (Future) Web interface
└── notebooks/      # Analysis notebooks
```

## Scope
All cardiovascular diseases including:
- Arrhythmias
- Coronary artery disease
- Heart failure
- Cardiomyopathies
- Hypertension
- Stroke
- Valvular heart disease

## Approach
Using BaseAgent (agentic AI tool) to build knowledge graph from curated biomedical databases, then filtering/tailoring for CVD-specific content.
