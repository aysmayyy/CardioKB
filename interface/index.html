    Welcome to CardioKB

    CardioKB is a general-purpose biomedical knowledge graph integrating 26 deduplicated data sources into a single queryable network. It connects genes, diseases, drugs, pathways, clinical trials, phenotypes, variants, and more — focused on cardiovascular disease with disease-agnostic base data.

    • 4.9M+ nodes across 19 entity types, 9.3M+ relationships from 26 sources
    • Search any disease (heart failure, Alzheimer's, lupus...) or any gene/drug
    • Build Knowledge Graph — AI fetches fresh data for any disease you name
    • Add entirely new databases — the AI-powered DatabaseAgent writes the parser for you

    Build Knowledge Graph AI

    In the sidebar, Build Knowledge Graph uses AI to enrich the graph for any disease:

    • Type any disease name — abbreviations, synonyms, and informal names all work (e.g. "PD", "lupus", "COPD")
    • AI standardizes the name, then fetches gene-disease associations from DisGeNET and clinical trials from ClinicalTrials.gov
    • Data is loaded into Neo4j and cached — the same disease returns instantly next time
    • After building, the Explore tab auto-opens with your disease so you can visualize the results immediately

    Extract Disease Subgraph (below it) queries existing data only — use Build first if coverage is thin.

    Explore & Query

    The Explore tab visualizes disease/gene subgraphs:

    • Search any disease or gene — type a name and click Explore
    • Core nodes (large, solid) are direct known associations
    • Discovery nodes (small, dashed) are 2-hop hypothesis-generating connections
    • Click any node to see its properties, neighbors, and specificity score
    • Use filter chips to show/hide entity types

    The Query tab gives you direct Cypher access — click a template or write your own (read-only, Cmd+Enter to run).

    Admin: Add New Databases AI

    Under Advanced in the sidebar (password-protected), the Add New Database panel lets you expand the graph with any public data source:

    • Enter a database name and a direct download URL (TSV, CSV, JSON, or gzipped)
    • Click Build Parser — the DatabaseAgent (Claude AI) samples the file, generates a complete parser, integrates it into the pipeline, and loads the data into Neo4j
    • The agent handles format detection, column mapping, ontology config, and ID validation automatically

    Also in Admin: Run Pipeline (full rebuild of all 26 sources).

    How to Read the Graph

    Two-layer architecture

    • Core layer — Direct (1-hop) neighbors of the searched entity. These are known, literature-backed associations from databases like OpenTargets, ClinVar, and DrugBank. Shown as large nodes with solid borders.
    • Discovery layer — 2-hop neighbors reached through core nodes. These are hypothesis-generating connections not directly linked to the disease — useful for finding shared pathways, off-target drugs, or comorbidity bridges. Shown as small nodes with dashed borders and faded edges. Toggle this layer on/off with the checkbox above the graph.

    Disease-specificity scoring

    • Every node has a pre-computed specificity score = 1 / (number of diseases it connects to)
    • A gene linked to only 1 disease scores 1.0 (highly specific); a gene linked to 500 diseases scores 0.002 (broadly connected, less informative for any single disease)
    • Disease nodes themselves score 0.0; nodes with no disease connections score 1.0
    • Use specificity to prioritize — high-specificity genes and drugs are more likely to be biologically meaningful for your disease of interest

    Node sizing & shapes

    • Diseases are diamonds; all other types are circles
    • Core nodes are larger; discovery nodes are smaller
    • Colors indicate entity type (see legend below graph)

    Reading edges

    • Solid edges = core (known) relationships
    • Dashed edges = discovery (inferred) connections
    • Edge labels show the relationship type (e.g., ASSOCIATES_WITH, TARGETS)
    • Each edge carries a source property identifying the originating database

    Thin results?

    • If a disease shows few connections, use Build Knowledge Graph in the sidebar to fetch fresh gene-disease associations and clinical trials via AI, then re-explore.
